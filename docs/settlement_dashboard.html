方法论（v0.3）：Olist 公开订单 → 72 条合同费率（8 承运商 × 3 服务区 × 3 重量带）算逐单合同应付 → 合成含 6 类注入差异的承运商账单 → SQL(DuckDB) 三方对账 → 规则复核建议（人工审批，不执行资金动作）→ Python 账龄/DSO/ECL。注入标签只在规则执行后用于评分。全流程一键复现，数据与产物均可由脚本重建。 本报告为个人项目（合成数据）成果展示，非京东真实经营数据。
